> [!warning] Callout
> Callouts are Obsidian's own syntax, not standard Markdown. Paperize keeps the text and marks the rest as simplified instead of failing the export.

The same holds for formulas, which Obsidian renders as graphics:

$$
c = \sqrt{a^2 + b^2}
$$

Both are counted, and the notice tells you how many elements were simplified.
